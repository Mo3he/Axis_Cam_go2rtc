Configure streams from the dashboard's Config tab. Settings are stored on the device and survive restarts.

HomeKit Secure Video

HKSV is not part of stock go2rtc, so it's not on by default. Add a homekit: block to the config for each stream you want to expose, e.g.:

homekit:
  outdoor:
    hksv: true
    motion: continuous

Full options (PIN, motion modes, doorbell category, ONVIF motion) are in the fork's HomeKit docs.
